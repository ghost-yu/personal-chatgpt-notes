## 原单元 3（markdown）

MHA=multi-head attention，Hkv=Hq；MQA=multi-query attention，Hkv=1；GQA的中间情形1<Hkv<Hq。Hq一般保持不变，所以每个Q head仍有自己的注意力权重和输出。减的是KV投影通道及持久缓存。

原文给MHA写computationally low容易误导：在相同Hq/d/token长度下，MHA不具备MQA的KV缓存节省。不能把MHA/MQA简单标为固定的高/低“质量”；论文比较取决于具体训练、模型和指标。原GQA论文Table1是T5实验，不能直接当Llama2原模型性能，也不能把共享当作无损地改任意checkpoint。

计算注意力分数的Q head数仍为Hq，naive repeat实现还可能创建临时展开副本。持久KV容量降低不意味着所有计算、总模型参数、延迟都按相同比例降低。

## 原单元 4（markdown）

原段中的“multiple key-value heads share the same query”把共享方向说反了：多个Q heads共享一个K head和对应V head，Q彼此不同。下面给出三条view、n_rep和两条local-head计算的逐语句注释，原Markdown保留。

xq/xk/xv来自不同可训练投影，是浮点Tensor，不是token整数。D为输入隐藏通道，B=bsz，S=seqlen，d=head_dim。Q投影输出[B,S,Hq_local*d]，view拆成[B,S,Hq_local,d]；K/V是[B,S,Hkv_local*d]，view拆成[B,S,Hkv_local,d]。view保持元素数量，将投影输出拆出head轴；原片段未给出三投影、bsz/seqlen赋值、cache或最终输出，不能单独运行。

self.n_rep=Hq_local//Hkv_local是每组有多少Q heads。//是整数向下取整，不是合法性检查；配置需保证整除，否则可能在后续matmul报head维不匹配。n_rep记录每组查询头数，Hkv记录组数。70B例子64/8=8，图中则8/4=2，二者都成立。

原文行内n_kv_heads == 8使用双等号，是比较表达式，返回bool，并不会把变量设成8；赋值使用单等号。这里它描述课程70B配置，不是通用模型要求。

model_parallel_size是模型并行rank数量，不是batch。两条local赋值将全局heads按rank切分；该固定简单实现要求head能均匀分片，Hkv过小的MQA不能直接任意增加rank数。实际验证只运行真实FairScale的world_size=1；没有通过算整除关系冒称多rank通信成功。

真正对齐heads的repeat_kv没有出现在原notebook。已另补固定官方函数和完整Attention类注释：输入[B,T,G,d]，新插入重复轴后expand为[B,T,G,R,d]，再reshape为[B,T,G*R,d]。这里G=Hkv_local,R=n_rep，顺序是每组连续重复，不是把整套head循环复制。

完整Attention先把少量KV写入缓存，再对有效前缀repeat_kv，最终QKᵀ→mask→softmax→乘V→合并heads→wo。输出[B,S,D]；每层cache被更新。原两代码格只导入和展示图片，所以官方前向、梯度及转换验证是明确补充，不能说它们原本就在notebook里。

```python
# Q拆成[B,S,Hq_local,d]，query head数保持不变。
xq = xq.view(bsz, seqlen, self.n_local_heads, self.head_dim)

# K拆成[B,S,Hkv_local,d]，仅投影较少的KV通道。
xk = xk.view(bsz, seqlen, self.n_local_kv_heads, self.head_dim)

# V与K共用分组数量，但投影权重和内容不同。
xv = xv.view(bsz, seqlen, self.n_local_kv_heads, self.head_dim)

# 每组有R个Q heads，//不自动检查是否整除。
self.n_rep = self.n_local_heads // self.n_local_kv_heads

# 当前rank的Q head数；world_size=1时等于全局数。
self.n_local_heads = args.n_heads // model_parallel_size

# 当前rank的KV head数，不是query数量，也不是batch。
self.n_local_kv_heads = self.n_kv_heads // model_parallel_size
```
