## 原单元 2（markdown）

公式来自 scaled dot-product attention。每个 head 的 Q=[B,S,d]、K/V=[B,P+S,d]，QKᵀ=[B,S,P+S]，除以 √d 后沿 key 轴 softmax，再乘 V 得 [B,S,d]。B=batch，S=本次输入长度，P=已缓存长度，d=head_dim。这里还需要因果 mask，原公式没有写出 mask 项。

KV cache 保存每层旧 token 的 key/value。decoder-only 自回归推理通常使用它；T5 decoder 可缓存 self-attention KV，也可复用 encoder cross-attention KV。原文的 BERT 说法应理解为常规双向 encoder 用法不采用这种逐 token 自回归缓存，不能推出所有配置永远不支持缓存。未来 token 会改变双向旧位置的隐藏状态，不能直接套用因果复用条件。

## 原单元 3（markdown）

CLM=causal language modeling，causal 表示位置 i 只能读取不晚于 i 的 token。推理使用最后位置的 logits 预测下一 token；训练可一次并行计算所有位置，但用三角 mask 防止看到未来答案。

## 原单元 4（markdown）

NTP=next token prediction。训练输入与目标错开一位：输入 SOS,Love,that 的目标是 Love,that,can。模型输出每位置词表 logits，交叉熵对齐下一位置。表格的 Output 是累计生成文本，而非一次 forward 产生整串。无 cache 每步重算完整前缀；有 cache 首次 prefill 处理提示词，再把上一步生成的 token 单独送入模型。EOS 是结束 token；实际 tokenizer 特殊标记与这张英文示意表不一定同名。

## 原单元 10（code）

## 原单元 11（markdown）

按每 head 单 token 情形，q=[1,d]，K/V=[P+1,d]，qKᵀ=[1,P+1]，softmax 后乘 V 得 [1,d]。K/V 包含当前 token 行，不能漏掉它。原文把 V 写作 weighted sum 不准确：V 是未聚合的 value 行，最终 Attention 输出才是加权和。旧 Q 不被未来 query 使用，因此常规实现只缓存 K/V。

## 原单元 12（code）

## 原单元 18（markdown）

这是 Attention(nn.Module) 的不完整摘录，下面保留每条语句并增加注释。class 表示类，nn.Module 是父类，self 指实例；__init__ 是构造方法，forward 是调用模型时的前向方法。完整源码先调用 super().__init__() 注册模块，并定义 head 数等属性；摘录缺这些步骤，还缺 bsz,seqlen=x.shape[:2]、辅助函数、最终注意力运算和返回，因此不能直接实例化运行。

args 是 ModelArgs，dim=D；start_pos=P 是本次首 token 的绝对位置；x 是每层归一化后隐藏状态浮点[B,S,D]。freqs_cis 为本次 P:P+S 的 complex64[S,d/2]。mask 允许 None；完整 Attention 接受可广播到[B,Hq_local,S,P+S]的浮点因果 mask。

ColumnParallelLinear 分片输出通道，RowParallelLinear 分片输入通道；本次验证 world_size=1，不能据此证明多 rank 通信。Wq 输出Hq_local*d通道，Wk/Wv 输出Hkv_local*d通道。view 拆 head；apply_rotary_emb 仅旋转 Q/K。cache_k 保存旋转后的 K，cache_v 保存未旋转 V。

torch.zeros 预分配固定容量[Bmax,Tmax,Hkv_local,d]；.cuda() 强制上 GPU；.to(xq) 匹配 xq 的设备及 dtype，不是把 Q 存入缓存。cache 是普通 Tensor 属性，不是 nn.Parameter 或 register_buffer，state_dict 不保存它，模型.to(...)也不自动迁移这些普通属性，所以 forward 显式处理。

切片赋值只覆写[0:B,P:P+S]，容量不增长。读取[:B,:P+S]将旧缓存与新增区域一起暴露，未来预分配槽不参与计算。切片通常为共享存储 view，并不是复制整个缓存。原注释“append”是逻辑追加，不能理解为 torch.cat 重新分配。

完整源码还执行 repeat_kv（GQA 展开）、transpose、QKᵀ/√d、mask、softmax、乘 V、合并 heads、wo，返回[B,S,D]。这里只摘录到 keys/values；逐层 cache 更新属于有状态推理，需要正确连续位置、相同前缀和 batch 顺序。新会话从0重新写有效前缀，读范围必须不包含旧尾部。

固定旧版 Transformer.forward 的 mask 在 P>0 且 S>1 时 shape 错误。本讲验证分别记录原版报错与一条 mask 赋值的教学修正，不将修正写进原 notebook。详见解释及复现报告。

### 摘录的逐语句注释

```python
# nn.Module 子类的摘录；缺 super 初始化及部分属性，不能单独运行。
class Attention(nn.Module):
    """Multi-head attention module."""
    # 构造方法：args提供D、head数和最大batch/长度等配置。
    def __init__(self, args: ModelArgs):

        # Q投影：实际本rank输出[B,S,Hq_local*d]。
        self.wq = ColumnParallelLinear(args.dim, args.n_heads * self.head_dim)
        # K投影：输出[B,S,Hkv_local*d]。
        self.wk = ColumnParallelLinear(args.dim, self.n_kv_heads * self.head_dim)
        # V投影：输出[B,S,Hkv_local*d]。
        self.wv = ColumnParallelLinear(args.dim, self.n_kv_heads * self.head_dim)
        # 合并heads后投影回D通道；完整类在末尾调用它。
        self.wo = RowParallelLinear(args.n_heads * self.head_dim, args.dim)


        # [8, 1024, 32, 128]
        # 预先分配固定容量的缓存张量，作为普通属性保存各位置的 K/V。
        self.cache_k = torch.zeros(
            (
                # 轴0为最大batch容量，实际只使用前B行。
                args.max_batch_size,    # 8
                # 轴1为最大token容量；切片写入，不动态扩容。
                args.max_seq_len,       # 1024, 不断地在这个维度上append keys
                # 轴2为当前rank的KV heads，不一定等于Q heads。
                self.n_local_kv_heads,  # 32
                # 轴3为每head通道d=D/Hq。
                self.head_dim,          # 128
            )
        # 原版强制CUDA；CPU教学模块仅显式修改这两处设备调用。
        ).cuda()

        #  [8, 1024, 32, 128]
        # 预先分配固定容量的缓存张量，作为普通属性保存各位置的 K/V。
        self.cache_v = torch.zeros(
            (
                # 轴0为最大batch容量，实际只使用前B行。
                args.max_batch_size,    # 8
                # 轴1为最大token容量；切片写入，不动态扩容。
                args.max_seq_len,       # 1024, 不断地在这个维度上append values
                # 轴2为当前rank的KV heads，不一定等于Q heads。
                self.n_local_kv_heads,  # 32
                # 轴3为每head通道d=D/Hq。
                self.head_dim,          # 128
            )
        # 原版强制CUDA；CPU教学模块仅显式修改这两处设备调用。
        ).cuda()

    # 前向方法在本实例上写cache；摘录缺输入shape解包和最终return。
    def forward(
        self,
        # 输入浮点隐藏状态[B,S,D]，不是token整数ID。
        x: torch.Tensor,
        # P为本次首token绝对位置，也是写缓存切片的起点。
        start_pos: int,
        # 本次位置P:P+S的复数频率[S,d/2]，由上层切片。
        freqs_cis: torch.Tensor,
        # None或可广播的因果mask，完整得分shape[B,Hq_local,S,P+S]。
        mask: Optional[torch.Tensor],
    ):
        # 三次投影只计算本次S个token，旧KV不重新投影。
        xq, xk, xv = self.wq(x), self.wk(x), self.wv(x)

        # 把投影通道拆为Q heads，得到[B,S,Hq_local,d]。
        xq = xq.view(bsz, seqlen, self.n_local_heads, self.head_dim)
        # 轴2为当前rank的KV heads，不一定等于Q heads。
        xk = xk.view(bsz, seqlen, self.n_local_kv_heads, self.head_dim)
        # 轴2为当前rank的KV heads，不一定等于Q heads。
        xv = xv.view(bsz, seqlen, self.n_local_kv_heads, self.head_dim)

        # Q/K按绝对位置旋转，V不旋转；缓存K是此后的结果。
        xq, xk = apply_rotary_emb(xq, xk, freqs_cis=freqs_cis)

        # 匹配Q的设备和dtype，不是保存Q；转换可能重分配。
        self.cache_k = self.cache_k.to(xq)
        # 匹配Q的设备和dtype，不是保存Q；转换可能重分配。
        self.cache_v = self.cache_v.to(xq)


        # 原地覆写当前[B,P:P+S]区域；此前KV保持不变。
        self.cache_k[:bsz, start_pos : start_pos + seqlen] = xk
        # 原地覆写当前[B,P:P+S]区域；此前KV保持不变。
        self.cache_v[:bsz, start_pos : start_pos + seqlen] = xv

        # 这里在复用之前的计算, all_past
        # 读取已用前缀P+S，包括当前新KV，排除未写入的容量尾部。
        keys = self.cache_k[:bsz, : start_pos + seqlen]
        # 读取已用前缀P+S，包括当前新KV，排除未写入的容量尾部。
        values = self.cache_v[:bsz, : start_pos + seqlen]
```
